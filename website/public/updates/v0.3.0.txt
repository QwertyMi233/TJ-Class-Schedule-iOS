# TJ Class Schedule 0.3.0：一个会帮你找东西的课表

同学们好，0.3.0 打包好了。

这次加了一个课表之外的小功能：记下东西放在哪里，需要时再按距离和方向找回去。自定义背景、备忘录和同步提示也一起改了。

## 定位寻物

课表右上角多了个定位按钮，就在作业按钮旁边。保存位置时可以起名字、写备注，支持保存多个点，编辑其中一个不会影响其他点，长按可以删除。

需要返回时，打开寻找页查看直线距离和动态方向，可选择箭头或方向高亮，横竖屏都能使用。位置只存在手机本地，只有保存或寻找时使用定位与方向传感器，退出或切到后台后停止。不授予定位权限也不影响课表和作业。

## 背景图与课表更协调

浅色模式用浅色蒙层，深色模式用暗色蒙层。新增“背景柔化”，可从 0 调到 20，默认 6，调到 0 保留原图；柔化只作用于图片，文字和按钮保持清晰。

修复换图后仍显示旧图、整周课表盖住背景、横屏和大字体下裁剪框溢出的问题。保存新图失败时保留旧图，图片损坏或丢失时恢复纯色界面。背景功能还会继续调整，欢迎反馈实际使用中遇到的问题。

## 备忘录和同步

一次性备忘录只填开始时间就能保存，需要记录时间段时再设置结束时间。自动同步不再反复弹底部提示，手动刷新保留简短反馈。

Canvas 可在官方页面登录后开启自动续期；学校要求重新认证、网页登录状态失效时，仍可能需要手动登录，不能保证一直免登录。未开启自动续期时，仍可按原方式使用个人访问令牌。

好课会定期维护连接。后台临时网络失败后有限补试，恢复后清除对应错误，手动刷新也可立即重试。提示简化为“网络不稳定，稍后自动重试”“请重新登录好课”等短句。

同时修复重叠安排未结束就提前跳到明天、同步后旧课程筛选隐藏新作业等问题，保留此前的启动卡住修复。

## 安装与说明

- Android 8.0 及以上，64 位 ARM 手机（arm64-v8a）。
- 直接覆盖安装保留课表、作业与定位点，无需卸载。若提示签名冲突，请先备份并联系反馈群，不要直接清除数据。
- 版本 0.3.0+12，versionCode 2012，签名与此前本地更新包一致。
- 课表、作业和定位点存本机；定位点不包含在课表 JSON 备份中。平台凭证使用系统安全存储，同步直连平台，不经过开发者服务器。
- 396 项 Flutter 测试、5 项 Android 单元测试与构建检查通过。熄屏同步仍受手机省电策略影响，尚未在全部机型验证；背景功能也需要继续观察真机表现。
