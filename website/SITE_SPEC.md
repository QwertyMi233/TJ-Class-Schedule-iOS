# TJ Class Schedule 官网改版约束

## 固定技术与组件

- Vite + React + TypeScript。
- Tailwind CSS 与 shadcn/ui（Radix 风格），实际使用 `Button`、`Carousel`、`Dialog`、`Accordion`、`Sheet`。
- 图标只用 `lucide-react`；App 图标使用原图优化版。
- 轮播使用 shadcn/ui 的 Carousel，手动点击、拖动或滑动；不自动播放。
- 原有六张用户截图保留。0.3.0 按用户要求新增寻物展示：使用 App 实际 Flutter 页面渲染的 `finder.webp`，标注示例位置，不制作仿造界面。
- 下载次数使用 Cloudflare Pages Function + D1，页面只读取与递增汇总数字；配置见 `COUNTING.md`。

## 固定视觉与布局

- 以参考站 [RikkaHub](https://rikka-ai.com/) 的居中导航、居中大标题、宽幅产品视觉为布局方向；不复制其插画、文案或品牌。
- 从上至下只走一条纵向阅读路径：导航 → 居中首屏 → 隐私短句 → 截图轮播 → 下载入口 → 入群入口 → 页脚。
- 大面积白与近黑、灰阶为主；`#607D8B` 只用于细节强调。真实截图保留原色。
- 标题留白充足、文字尽量短。功能文案每项一句，不堆功能清单。
- 动效限于首屏淡入、滚动浮现和悬停反馈；系统要求减少动态效果时关闭。
- 安装须知、隐私细节、常见问题通过清晰的按钮打开原生可操作的 shadcn 对话框或折叠项；入口位于相关区块。
